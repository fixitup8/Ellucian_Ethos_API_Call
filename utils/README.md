# Utilities

This location contains python scripts used to call the API and generate mock
responses which can be loaded into tests.

## Postman collection examples

The rest of the scripts here (`get_access_token.py`, `list_*.py`, `create_person.py`,
`update_person.py`, `publish_*.py`, `consume_change_notifications.py`) are Python
translations of the requests in
[`Ethos Integration Examples.postman_collection.json`](../Ethos%20Integration%20Examples.postman_collection.json)
(in the repo root), one script per Postman request. See
[docs/POSTMANEXAMPLES.md](../docs/POSTMANEXAMPLES.md) for the full script-to-request
mapping and setup notes.
